# 📊 Data Analysis & Statistics (R)
**Probability & Statistics Course**  
📍 *Universidad Tecnológica Nacional (UTN)*

## 📘 Project Overview: Innova XXII Case Study
This repository contains statistical analysis performed on a dataset from **Universidad INNOVA XXII** (Ushuaia). The study analyzes student characteristics, academic performance, and satisfaction levels to improve institutional quality.

## 🚀 Analysis Techniques Applied
*   **Descriptive Statistics:** Frequency tables (Absolute, Relative, Cumulative).
*   **Data Visualization:** Histograms and Circular (Pie) Charts.
*   **Central Tendency & Dispersion:** Calculation of Mean, Median, Mode, and Quartiles.
*   **Technical Precision:** All calculations follow symmetric rounding with 4 decimal places.

## 📂 Repository Structure
*   `data/`: Contains the raw dataset (Excel/CSV format).
*   `scripts/`: R scripts organized by assignment delivery.
    *   `assignment_1.R`: Frequency tables and initial interpretation.
    *   `assignment_2.R`: Descriptive measures and graphical analysis.

## 📈 Variables Analyzed
*   **Study Time:** Weekly hours dedicated to home study.
*   **Academic Satisfaction:** Qualitative ordinal variable (From "Very Unsatisfied" to "Very Satisfied").
*   **Socioeconomic Factors:** Age, gender, weight, height, and employment status.
